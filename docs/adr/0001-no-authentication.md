# No authentication or ownership

`slug-pages` is a zero-friction scratchpad: anyone with a slug's link can read and write it, immediately, with no account. Adding authentication or per-page ownership would remove the "type a URL, start typing" experience that is the whole point of the product.

**Consequences**: anyone who guesses or obtains a slug can read, overwrite, or clear its content — there is no privacy, ownership, or recovery. This is deliberate, not a gap; do not add auth or access control without revisiting this decision first.
